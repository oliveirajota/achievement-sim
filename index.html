Como usar no OBS
  1. No OBS: Fontes → + → Navegador. Desmarque Arquivo local e cole o link abaixo no campo URL.
  2. Largura/altura = a resolução escolhida (ex.: 1920 × 1080).
  3. Marque Controlar áudio via OBS (o som aparece no mixer) e Desligar a fonte quando não estiver visível.
  4. Para disparar: ligue o olho 👁 da fonte. Cada vez que ela aparece, a animação toca. Dica: em Configurações → Teclas de atalho, defina um atalho de “Mostrar/Ocultar” para essa fonte.
  5. Ícone ou som próprios: coloque os arquivos na mesma pasta deste index.html e digite o nome nos campos “para o OBS”.

Abrir o modo OBS numa aba para testar (clique na página ou aperte espaço para disparar).

Exportar vídeo para redes sociais
  1. Use Chrome ou Edge e mantenha esta aba visível durante a gravação (dura alguns segundos).
  2. Para TikTok/Reels/Shorts/YouTube, use fundo Preto ou Verde (chroma) — essas plataformas não aceitam transparência. O verde dá para recortar em qualquer editor (CapCut, Premiere, DaVinci).
  3. Transparente só faz sentido em WebM, e depende do navegador gravar o canal alfa. Se o resultado vier com fundo preto, use o verde.
  4. MP4 só aparece se o navegador suportar gravar nesse formato; senão, grave em WebM.
  5. Só a conquista (recorte): grava apenas a área do popup (a linha tracejada na prévia), com folga para sombra e brilho. Bom para usar como camada no CapCut/Premiere/DaVinci: grave em WebM transparente ou em verde e posicione onde quiser.
